# Аманат-А v2

Автономный статический сайт. Никаких npm/сборщиков не требуется.

## Публикация
1. Удалите старые файлы сайта в репозитории (можно оставить историю Git).
2. Загрузите содержимое этого архива в корень репозитория.
3. Commit changes.
4. Vercel, подключенный к production-ветке, опубликует обновление автоматически.
